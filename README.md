# Ibex Expeditions

Web de la travessa de 5 dies pel Parc Nacional del Triglav (Eslovènia).
*Travesses al cor dels Alps Julians.*

## Estructura

```
index.html      Pàgina principal
dia1.html       Dia 1: Bohinjska Bistrica → Planinska koča na Vojah
css/style.css   Estils
js/main.js     Menú i animacions
```

## Publicar-la a GitHub Pages

1. Crea un repositori nou a GitHub i puja-hi tots els arxius.
2. Ves a **Settings → Pages**.
3. A *Source* tria **Deploy from a branch**, branca `main`, carpeta `/ (root)`.
4. Al cap d'un minut la web serà a `https://EL-TEU-USUARI.github.io/NOM-DEL-REPO/`.
